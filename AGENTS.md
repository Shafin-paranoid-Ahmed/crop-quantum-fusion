# Repository guidance

Read README.md, RUN_COMMANDS.md, provenance/CHANGES.md and provenance/VERIFICATION.md first.
Use an explicit Python interpreter. This repository is independent of the parent thesis checkout.
Do not regenerate splits, overwrite canonical models/results, launch official experiments, or publish without user authorization.
Preserve pseudo/generated training-label provenance and negative results. Never infer quantum advantage from calibration alone.
Existing experiment documents are historical; root runbook takes precedence for current paths.
